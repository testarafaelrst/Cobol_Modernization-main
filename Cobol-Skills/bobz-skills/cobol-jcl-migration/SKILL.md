# Skill: JCL and Procedure Migration — COBOL II to Enterprise COBOL 6.5

Follow these steps when the user needs to update compile JCL or a cataloged
procedure for Enterprise COBOL 6.5.

## Step 1 — Capture the Current JCL

Ask the user to paste their current compile procedure or JCL if not already
provided. Identify:

- How many steps are present: DB2PREC (DSNHPC), CICSTRAN (DFHECP1$), COBCOMP, LNKPGM
- Current PARM string on the compile step
- STEPLIB / SYSLIB datasets referenced
- Whether a `DBRMLIB` DD is present and where

## Step 2 — Remove Pre-processing Steps

Produce explicit `REMOVE` annotations for:

1. **DB2PREC step** (`PGM=DSNHPC`) — entire step
2. **CICSTRAN step** (`PGM=DFHECP1$`) — entire step
3. **Temporary datasets** `&&DB2OUT` and `&&CICSOUT` — all DD references
4. **SYSCIN DD** from the old COBCOMP step (was receiving DSNHPC output)

## Step 3 — Update the Compile Step

Show the updated COBCOMP step with these changes:

```jcl
//COBCOMP  EXEC PGM=IGYCRCTL,
//    REGION=0M,
//    PARM=('APOST,LIB,RENT,OPT(FULL),NODYNAM,NODECK,NOSSRANGE',
//          'CICS(''COBOL2''),SQL,ARCH(10),TUNE(10)',
//          'INVDATA(NOFIXUP),NUMCHECK,INITCHECK,TEST(NODWARF)')
//STEPLIB  DD DSN=IGY.V6R5M0.SIGYCOMP,DISP=SHR  <- update version
//SYSLIB   DD DSN=BANCO.CICS.COPYLIB,DISP=SHR
//         DD DSN=BANCO.DB2.DCLGEN,DISP=SHR
//         DD DSN=CICS.SDFHCOB,DISP=SHR
//         DD DSN=CEE.SCEEH,DISP=SHR             <- ADD LE headers
//DBRM     DD DSN=BANCO.DBRMLIB(&MEMBER),DISP=SHR  <- ADD for SQL
//SYSIN    DD DSN=&LIB(&MEMBER),DISP=SHR         <- source directly
```

Key annotation for each change:
- `REGION=0M` — EC 6.5 uses storage above the 2GB bar; required
- `CICS('COBOL2')` — replaces the removed DFHECP1$ step
- `SQL` — replaces the removed DSNHPC step
- `DBRM DD` — receives DBRM output from the integrated coprocessor
- `CEE.SCEEH` in SYSLIB — LE header copybooks
- `SYSIN` points to the **original source** (not `&&CICSOUT` or `&&DB2OUT`)

## Step 4 — Update the Link-Edit Step

```jcl
//SYSLIB DD DSN=CICS.SDFHLOAD,DISP=SHR
//       DD DSN=DSN.SDSNEXIT,DISP=SHR
//       DD DSN=DSN.SDSNLOAD,DISP=SHR
//       DD DSN=IGY.V6R5M0.SIGYCOMP,DISP=SHR  <- update version
//       DD DSN=CEE.SCEERUN,DISP=SHR           <- LE runtime (replaces COB2.SCOB2LKE)
*REMOVE:
*//     DD DSN=COB2.SCOB2LKE,DISP=SHR
*//     DD DSN=COB2.SCOB2LOD,DISP=SHR
```

## Step 5 — Add CEEOPTS DD (Optional)

For programs needing specific LE runtime options:

```jcl
//CEEOPTS DD *
  TRAP(ON,NOSPIE)
  STORAGE(00,00,00)
  RPTOPTS(ON)
/*
```

## Step 6 — Produce a Step Count Summary

Show the reduction:

| | COBOL II | EC 6.5 |
|---|---|---|
| DB2 precompile step | ✅ DB2PREC | ❌ Removed |
| CICS translate step | ✅ CICSTRAN | ❌ Removed |
| Compile step | ✅ COBCOMP | ✅ COBCOMP (updated) |
| Link-edit step | ✅ LNKPGM | ✅ LNKPGM (updated) |
| **Total steps** | **4** | **2** |

## Step 7 — Remind About BIND

If the program has DB2 access, the BIND step must be re-executed after
recompilation using the new DBRM generated by the integrated coprocessor.
Reference: `Cobol-Skills/skill-jcl-procedures.md` §"BIND DB2".
