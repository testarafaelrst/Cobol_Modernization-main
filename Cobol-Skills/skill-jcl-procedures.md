# Skill: JCL and Compile Procedures — COBOL II to EC 6.5

> Sources: `skill-migration-v65.md` §Ch.20 "JCL and packaging changes" /
> `skill-perf-tuning.md` §"CICS" and §"IMS"

---

## 1. Overview of JCL Changes

| Component | COBOL II | Enterprise COBOL 6.5 |
|---|---|---|
| Compiler | `IGYCRCTL` v2.4 | `IGYCRCTL` v6.5 |
| Runtime library | `COB2.SCOB2LKE` | `CEE.SCEERUN` |
| CICS step | Separate `DFHECP1$` | `CICS` option in the compiler |
| DB2 step | Separate `DSNHPC` | `SQL` option in the compiler |
| Removed options | `RES`, `NORES`, `RESIDENT`, `CMPR2`, `SIZE` | — |
| New DDs | — | `DBRM DD`, `CEEOPTS DD` |
| MEMLIMIT | Not applicable | `REGION=0M` + `MEMLIMIT=3G` (compilation) |

## 2. Compile Procedure — Full Comparison

### 2.1 COBOL II Procedure (before)

```jcl
//COBIIPROC PROC MEMBER=,LIB=BANCO.CICS.SRC,
//               LOADLIB=BANCO.CICS.LOAD
//*
//*--- STEP 1: DB2 PRECOMPILE ---
//DB2PREC  EXEC PGM=DSNHPC,
//             PARM='HOST(COBOL),VERSION(AUTO),APOSTSQL(YES)'
//DBRMLIB   DD DSN=BANCO.DBRMLIB(&MEMBER),DISP=SHR
//SYSCIN    DD DSN=&&DB2OUT,DISP=(NEW,PASS),
//             UNIT=SYSDA,SPACE=(TRK,(10,5))
//SYSLIB    DD DSN=BANCO.CICS.COPYLIB,DISP=SHR
//          DD DSN=BANCO.DB2.DCLGEN,DISP=SHR
//SYSPRINT  DD SYSOUT=*
//SYSIN     DD DSN=&LIB(&MEMBER),DISP=SHR
//*
//*--- STEP 2: CICS TRANSLATOR ---
//CICSTRAN  EXEC PGM=DFHECP1$,
//              PARM='COBOL2,CICS'
//SYSLIB    DD DSN=BANCO.CICS.COPYLIB,DISP=SHR
//          DD DSN=BANCO.DB2.DCLGEN,DISP=SHR
//          DD DSN=CICS.SDFHCOB,DISP=SHR
//SYSUT1    DD UNIT=SYSDA,SPACE=(CYL,(1,1))
//SYSPUNCH  DD DSN=&&CICSOUT,DISP=(NEW,PASS),
//             UNIT=SYSDA,SPACE=(TRK,(15,5))
//SYSPRINT  DD SYSOUT=*
//SYSIN     DD DSN=&&DB2OUT,DISP=(OLD,DELETE)
//*
//*--- STEP 3: COBOL II COMPILE ---
//COBCOMP   EXEC PGM=IGYCRCTL,
//              PARM='APOST,LIB,RENT,RES,OPT,NODYNAM,NODECK'
//STEPLIB   DD DSN=IGY.V2R4M0.SIGYCOMP,DISP=SHR
//SYSLIB    DD DSN=BANCO.CICS.COPYLIB,DISP=SHR
//          DD DSN=BANCO.DB2.DCLGEN,DISP=SHR
//          DD DSN=CICS.SDFHCOB,DISP=SHR
//SYSUT1    DD UNIT=SYSDA,SPACE=(CYL,(2,1))
//SYSPRINT  DD SYSOUT=*
//SYSLIN    DD DSN=&&COBOUT,DISP=(NEW,PASS),
//             UNIT=SYSDA,SPACE=(TRK,(15,5))
//SYSIN     DD DSN=&&CICSOUT,DISP=(OLD,DELETE)

//*--- STEP 4: LINK-EDIT ---
//LNKPGM    EXEC PGM=IEWL,
//               PARM='LIST,LET,XREF,RENT,REUS'
//SYSLIB    DD DSN=CICS.SDFHLOAD,DISP=SHR
//          DD DSN=DSN.SDSNEXIT,DISP=SHR
//          DD DSN=DSN.SDSNLOAD,DISP=SHR
//          DD DSN=IGY.V2R4M0.SIGYCOMP,DISP=SHR
//          DD DSN=CEE.SCEERUN,DISP=SHR
//SYSPRINT  DD SYSOUT=*
//SYSLMOD   DD DSN=&LOADLIB(&MEMBER),DISP=SHR
//SYSLIN    DD DSN=&&COBOUT,DISP=(OLD,DELETE)
//          DD DDNAME=SYSIN
//SYSIN     DD *
 NAME &MEMBER(R)
/*
// PEND
```

```jcl
//EC65PROC  PROC MEMBER=,LIB=BANCO.CICS.SRC,
//               LOADLIB=BANCO.EC65.LOAD
//*
//*--- STEP 1: COMPILE (CICS + DB2 INTEGRATED) ---
//COBCOMP   EXEC PGM=IGYCRCTL,
//    REGION=0M,
//    PARM=('APOST,LIB,RENT,OPT(FULL),NODYNAM,NODECK,NOSSRANGE',
//          'CICS(''COBOL2''),SQL,ARCH(10),TUNE(10)',
//          'TRUNC(OPT),INVDATA(NOFIXUP),NUMCHECK,INITCHECK',
//          'TEST(NODWARF)')
//*
//STEPLIB   DD DSN=IGY.V6R5M0.SIGYCOMP,DISP=SHR
//SYSLIB    DD DSN=BANCO.CICS.COPYLIB,DISP=SHR
//          DD DSN=BANCO.DB2.DCLGEN,DISP=SHR
//          DD DSN=CICS.SDFHCOB,DISP=SHR
//          DD DSN=CEE.SCEEH,DISP=SHR
//SYSUT1    DD UNIT=SYSDA,SPACE=(CYL,(2,1))
//SYSUT2    DD UNIT=SYSDA,SPACE=(CYL,(2,1))
//SYSUT3    DD UNIT=SYSDA,SPACE=(CYL,(2,1))
//SYSPRINT  DD SYSOUT=*
//SYSLIN    DD DSN=&&COBOUT,DISP=(NEW,PASS),
//             UNIT=SYSDA,SPACE=(TRK,(15,5))
//DBRM      DD DSN=BANCO.DBRMLIB(&MEMBER),DISP=SHR
//*    ^^^^ DBRM generated by the integrated coprocessor
//SYSIN     DD DSN=&LIB(&MEMBER),DISP=SHR
//*         ^^^^ original source directly (no pre-processing)
//*
//*--- STEP 2: LINK-EDIT ---
//LNKPGM    EXEC PGM=IEWL,
//               PARM='LIST,LET,XREF,RENT,REUS',
//               COND=(4,LT,COBCOMP)
//SYSLIB    DD DSN=CICS.SDFHLOAD,DISP=SHR
//          DD DSN=DSN.SDSNEXIT,DISP=SHR
//          DD DSN=DSN.SDSNLOAD,DISP=SHR

//*              ^^^^^^^^^^^^ LE runtime (replaces COB2.SCOB2LKE)
//SYSPRINT  DD SYSOUT=*
//SYSLMOD   DD DSN=&LOADLIB(&MEMBER),DISP=SHR
//SYSLIN    DD DSN=&&COBOUT,DISP=(OLD,DELETE)

 NAME &MEMBER(R)
```

## 3. DD Statements — Changes

| DD | COBOL II | Enterprise COBOL 6.5 | Action |
|---|---|---|---|
| `STEPLIB` — compiler | `IGY.V2R4M0.SIGYCOMP` | `IGY.V6R5M0.SIGYCOMP` | Update dataset |
| `STEPLIB` — runtime | `COB2.SCOB2LKE` | **Remove** — LE is loaded automatically | Remove |
| `SYSLIB` — LE headers | Not required | `CEE.SCEEH` | Add |
| `SYSLIB` — CICS copybooks | `CICS.SDFHCOB` | `CICS.SDFHCOB` (same) | No change |
| `DBRM` | In the DSNHPC step | In the compile step | Move DD to COBCOMP |
| `SYSCIN` / `&&DB2OUT` | Output of DSNHPC | **Eliminate** | Remove |
| `&&CICSOUT` | Output of DFHECP1$ | **Eliminate** | Remove |
| `CEEOPTS` | Does not exist | Optional — LE runtime options | Add if needed |

## 4. REGION and MEMLIMIT for Compilation

Enterprise COBOL 6.5 uses storage **above the 2GB bar** to compile.
Without proper configuration, `IGYCB7145-U Insufficient memory` may occur.

```jcl
//COBCOMP   EXEC PGM=IGYCRCTL,
//    REGION=0M
//*
//* On the JOB card or via IEFUSI:
//JOBCARD   JOB ...,REGION=0M
//* And in the z/OS configuration:
//* MEMLIMIT=3G (minimum recommended for large compilations)
```

> **Ref:** `skill-migration-v65.md` §Ch.19 "Compiler behavior changes — MEMLIMIT"

## 5. CEEOPTS — LE Runtime Options

To control LE runtime options in batch:

```jcl
//CEEOPTS  DD *
  TRAP(ON,NOSPIE)
  STORAGE(00,00,00)
  RPTOPTS(ON)
/*
```

In CICS, LE options are configured in the CICS SIT (System Initialization
Table) or via `CEEUOPT` in the LE install parameters.

## 6. DB2 BIND — Continuity

The BIND process does not change. Only the `DBRMLIB` dataset needs to contain
the DBRMs generated by the new integrated coprocessor.

```jcl
//DSNBIND  EXEC PGM=IKJEFT01
//SYSTSPRT DD SYSOUT=*
//SYSTSIN  DD *
  DSN SYSTEM(DB2P)
  BIND PACKAGE(BANCPKG) -
       MEMBER(MYPGM)    -
       LIBRARY('BANCO.DBRMLIB') -
       ISOLATION(CS) VALIDATE(BIND) ACTION(REPLACE)
  END
/*
```
